# FilmAura — Production Model Artifacts

This directory contains the pre-computed machine learning artifacts exported by `notebooks/FilmAura_ML_Backend.ipynb` after training on the GroupLens MovieLens 32M dataset.

The Streamlit frontend (`app.py`) loads these files via `recommender.py` for sub-second recommendation inference without requiring retraining.

---

## Artifact Descriptions

| File | Type | Description |
| :--- | :--- | :--- |
| **`movies_catalogue.csv`** | CSV Data | Cleaned MovieLens film catalogue containing `movieId`, `clean_title`, `year`, `genres_list`, `tags_list`, `rating_mean`, `rating_count`, and heuristic `moods` affinity scores. |
| **`tfidf_vectorizer.pkl`** | Pickle (`joblib`/`sklearn`) | Fitted Scikit-Learn `TfidfVectorizer` mapping unigrams and bigrams from film titles, genres, and community tags. |
| **`tfidf_matrix.npz`** | Scipy Sparse Matrix (`CSR`) | Compressed sparse term-document matrix representing the content vectors for all catalogue titles. |
| **`svd_components.npy`** | NumPy Array | Latent item factors ($\mathbf{V}^T$) generated by TruncatedSVD matrix factorization on the user-item interaction matrix. |
| **`config.json`** | JSON Metadata | Model configuration, default hybrid weights, and 10-mood taxonomy. |

---

## How to Regenerate Artifacts
1. Open `notebooks/FilmAura_ML_Backend.ipynb` in Google Colab or Kaggle.
2. Run all cells (`Runtime -> Run all`).
3. The final cell will train the hybrid recommender on MovieLens and export these files.
4. Download the generated files into this `artifacts/` folder.
